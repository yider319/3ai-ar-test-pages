V1.2A.2 — 高度重複性診斷

在 Pixel Chrome 上，使用 WebXR 分別量出地板與桌面的位置。人工實測桌面離地約 73 公分，桌板厚約 1.6 公分。

  1. 按「開始 AR」，用綠色方塊選取地板，點畫面標記藍色地板點。
  2. 再從略高於桌面的角度，緩慢掃視桌面 10–20 秒。
  3. 看上方「綠色候選點相對地板高度」；接近 73 cm 時，再點畫面標記橘色桌面點。
  4. 若始終顯示接近 0 cm，先截圖回報，不要硬將地板點當桌面。
